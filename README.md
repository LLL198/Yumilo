# Yumilo

把自己的影视库，放进一个顺手的播放器。一款面向 Android 手机和平板的多功能 Emby 客户端（另提供 Android TV 版与 Windows 版）。

## 功能特色

- 📺 **多服管理与聚合搜索** - 支持添加多个 Emby 服务器，支持跨服聚合搜索与指定媒体库筛选
- 🏠 **自定义首页与推荐** - 自由添加卡片、选择数据源，把不同服务器和源的内容组合在一起，也可浏览每日缓存的推荐内容
- 💬 **弹幕支持** - 可配置弹幕 API，支持自动匹配、手动搜索及弹幕时间轴调整
- 🎮 **双核播放器** - 支持双播放内核切换、倍速播放、多音轨/字幕切换、字幕延迟调整、画面比例与片头片尾跳过
- 🔄 **进度同步与 Trakt** - 自动同步 Emby 播放进度，支持连接 Trakt 管理追更、查看播出日历与同步观看记录
- ⭐ **多平台评分** - 填入自己的 MDBList API Key 后，可在首页海报和详情查看 IMDb、TMDB、烂番茄、Letterboxd、Trakt、Metacritic 的可用评分，支持本地缓存
- 🌐 **多源扩展支持** - 除 Emby 外，支持挂载网盘、本地视频、自定义组件、TVBox 及 IPTV 资源
- 🎨 **个性化外观** - 提供白玻璃、毛玻璃和液态玻璃风格，支持深浅主题、海报背景与自定义徽章包
- ☁️ **无感备份还原** - 支持通过本地文件或 WebDAV 一键备份账号、设置、扩展源与播放记录

## 技术栈

- **UI 框架**：Android 原生 View + Canvas
- **播放器**：AndroidX Media3 + MPV + FFmpeg
- **弹幕引擎**：自定义 Canvas 弹幕渲染
- **网络**：OkHttp
- **图片加载**：Glide

## 使用说明

1. 安装对应设备的客户端并打开应用
2. 在“资源库”中手动添加或扫码（TV 版）配置 Emby 服务器
3. 添加服务后即可浏览媒体库、搜索并播放影视内容
4. 在“设置 -> 弹幕设置”中配置弹幕 API（可选）
5. 在“设置”中连接 Trakt 账号、添加网盘/组件源或配置 WebDAV 备份（可选）
