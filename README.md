# Yumilo

把自己的影视库，放进一个顺手的播放器。

Yumilo 是一款面向 Android 手机和平板的影视播放器，支持连接 Emby、浏览媒体库、观看弹幕和管理追剧。另有电视版和 Windows 版，可按设备选择下载。

**[下载 Android 版](https://github.com/LLL198/Yumilo/releases/latest)** · **[下载电视版](https://github.com/LLL198/YUMILO-TV/releases/latest)** · **[下载 Windows 版](https://github.com/LLL198/YUMILO-WINDOWS/releases/latest)**

## 功能特色

- **多个影视库，一处管理**：添加多个 Emby 服务器，浏览电影、剧集、演员和影片信息，随时切换资源。
- **一起搜索，自己选范围**：同时搜索多个服务器和已启用的源，也可以只找指定媒体库的内容。
- **按自己的习惯播放**：支持倍速、音轨与字幕切换、字幕时间调整、画面比例和片头片尾跳过；提供两种播放内核，可按影片情况切换。
- **看视频，也看弹幕**：添加弹幕接口后，可自动匹配影片，也能手动搜索和调整时间。
- **接着看，也方便追剧**：继续上次的播放进度；连接 Trakt 后，可管理追更、查看播出日历，并同步观看记录。
- **外观随心调整**：提供默认、磨砂玻璃和液态玻璃风格，支持深浅主题、海报背景与自定义徽章包。
- **更多播放方式**：支持网盘、本地视频，以及自己添加的组件、TVBox 和 IPTV 资源。
- **换设备时少折腾**：可备份账号、设置、源、组件及源播放记录，支持本地文件和 WebDAV 备份。

以上为 Android 手机和平板版的主要功能，电视版和 Windows 版的界面与功能有所不同。

## 下载安装

| 使用设备 | 下载入口 | 安装方式 |
| --- | --- | --- |
| Android 手机、平板 | [下载 Android 版](https://github.com/LLL198/Yumilo/releases/latest) | 下载 `.apk` 安装包后打开安装 |

安装后可在应用的设置中检查更新。

## 开始使用

1. 打开 Yumilo，在“资源库”中添加 Emby 服务器，填写服务器地址和自己的账号。
2. 进入首页或媒体库，选择电影、剧集并开始播放。
3. 想看弹幕，可在“设置 → 弹幕设置”中添加接口。
4. 想使用追更和播出日历，可在“设置 → Trakt”中连接账号。
5. 按自己的习惯调整“播放设置”和“外观”，也可以继续添加网盘、组件或其他资源。

使用电视版时，也可以通过手机扫码填写服务器信息。

## 常见问题

**安装后就能直接看片吗？**

需要先添加自己的服务器、网盘或其他资源。Yumilo 不提供影视内容，影片是否可用取决于你添加的资源。

**为什么没有弹幕？**

请先配置可用的弹幕接口。自动匹配不到时，可以在播放页面手动搜索对应的影片和集数。

**遇到播放失败怎么办？**

先确认服务器或源是否可用，再尝试切换播放内核。如果仍有问题，可在设置中导出诊断日志，反馈时附上设备型号、应用版本和复现步骤。

**更新会清空账号和记录吗？**

通常直接覆盖安装即可保留数据，不需要卸载旧版。更换设备或重新安装前，建议先在“备份与还原”中保存备份。
